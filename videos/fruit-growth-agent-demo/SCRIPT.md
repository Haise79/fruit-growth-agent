# 果序 Agent 完整操作演示字幕脚本

**形式：** 仅画面与中文字幕，无旁白、无音乐、无音效。

## 0:00–0:12 开场

果序 Agent：面向水果电商运营团队的多租户工作台。

这段演示使用完整虚构数据，不连接真实店铺，也不会执行真实退款、改价或发布。

## 0:12–0:32 建立演示会话

先选择“运营人员”，进入果序生鲜（华东）的演示空间。

右上角同时显示当前租户和角色；会话由真实 API 签发，并在三十分钟后失效。

## 0:32–0:50 成员与权限

同一租户内预置四名成员，对应负责人、运营、客服和实施四种封闭角色。

后端查询始终携带租户身份，避免跨租户读取。

## 0:50–1:10 商品 CSV 导入

下载中文演示 CSV，再上传校验。

其中一行商品合法，另一行库存为负。系统按行返回成功和失败，不会因为一条错误丢失整批结果。

## 1:10–1:32 知识与商品

知识库预置八条内容，覆盖已通过、草稿、已拒绝、过期和来源冲突。

价格与库存只走精确事实查询；过期或冲突内容不会进入 Agent 推荐。

## 1:32–1:52 人工审批

退款、改价、改库存和内容发布属于高风险动作。

界面只记录批准或拒绝，以及完整审计轨迹；这里没有任何真实外部执行器。

## 1:52–2:28 运营 Copilot

Copilot 接收客户问题，识别意图、情绪和风险等级，再生成最多三条候选建议。

每条建议都附带知识或商品事实引用，运营人员可以编辑、复制，并记录是否采纳。

高风险问题会提示转交人工，不会越权自动处理。

## 2:28–2:48 业务结果闭环

每个案例保留建议、引用快照、编辑记录和结果事件。

这些结构化数据可用于复盘采用率、风险处理和后续质量评估。

## 2:48–3:00 结束

从角色权限、商品数据、知识治理到审批、Copilot 和结果反馈，完整链路已经可以本地运行。

果序 Agent。人工确认优先，事实依据可追溯。
