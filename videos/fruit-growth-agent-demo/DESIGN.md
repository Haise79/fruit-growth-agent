# 果序 Agent 视频视觉规范

## Overview

果序 Agent 是一套克制、可信的企业运营后台。页面以白色大画布、固定左侧导航和细线分区构成，内容密度适中，层级依靠字号、留白和绿色强调建立。整体避免装饰性图形，把注意力放在角色、数据、审核和业务闭环上。视频保持真实产品界面为主体，字幕与转场只做清晰引导。

## Colors

- **品牌主绿**：`#075F42` — 标识、主按钮、状态徽章和字幕强调。
- **深绿文字**：`#034B34` — 当前导航、链接、重要标签。
- **薄荷底色**：`#EDF7F2` — 演示入口、选中态和轻量信息层。
- **正文黑**：`#171B19` — 标题和主要正文。
- **辅助深灰**：`#313834` — 普通导航文字。
- **说明灰**：`#69716D` — 描述、元信息、次级字幕。
- **分隔线**：`#DCE2DF` — 表格、卡片和页面边界。
- **浅绿边框**：`#B9DACD` — 演示区域边框。
- **风险红**：`#E64135` — 错误、拒绝和高风险状态。
- **主画布**：`#FFFFFF` — 页面及字幕卡主要表面。

## Typography

- **主字体**：Inter，400 用于正文，650 用于操作项，700–720 用于标题和品牌。
- **中文回退**：`PingFang SC`、`Microsoft YaHei`，保证 Windows 中文清晰可读。
- **辅助字体**：Geist，400–600，用于系统生成的界面层。
- **标题层级**：视频章标题 64–76px；字幕 34–40px；界面内标题保持真实页面比例。
- **数字与编码**：Geist Mono，使用等宽数字展示 SKU、计数和案例编号。

## Elevation

界面主要通过 `1px` 的 `#DCE2DF` 或 `#B9DACD` 边框形成层级，不使用厚重阴影。视频中的真实页面放在轻微圆角的浏览器画框内，可使用低透明度深绿阴影与 1.01–1.04 的慢速推近营造空间感；字幕条使用白底或 `#034B34` 底色，保证对比度。

## Components

- **固定侧边导航**：208px 白色栏，圆形“果”标识，选中项使用薄荷底和绿色左边线。
- **租户身份顶栏**：右上角显示当前租户和角色，是演示身份成功的主要证据。
- **本地演示入口**：薄荷色大区域，包含角色下拉框与深绿主按钮。
- **六步导览清单**：细线分隔的编号步骤，每步包含标题、说明和“打开功能”链接。
- **数据表格**：白底、浅灰表头、细线行分隔，适合通过框选与放大强调字段。
- **状态与风险文本**：绿色表示通过和安全，红色表示失败、拒绝或高风险。
- **Copilot 双栏工作区**：左侧输入与建议详情，右侧最近案例，强调从问题到结果的连续流程。
- **中文字幕条**：底部居中，最大宽度 1480px，深绿半透明底或白色实底，单次最多两行。

## Do's and Don'ts

### Do's

- 使用捕获到的精确品牌色，保持白底、绿强调和细边框。
- 让真实产品画面占据至少 80% 的可视面积。
- 使用缓慢推近、平移和框选高亮引导视线。
- 每个字幕停留足够时间，中文每屏控制在 14–28 字。
- 风险与错误场景使用 `#E64135`，成功状态使用 `#075F42`。

### Don'ts

- 不使用渐变霓虹、玻璃拟态、3D 图标或与后台气质无关的装饰。
- 不改变真实界面的颜色、文案和数据。
- 不使用快速闪烁、强烈旋转或大幅弹跳。
- 不添加旁白、背景音乐和音效。
- 不让字幕遮挡主按钮、表格关键行或 Copilot 建议。
