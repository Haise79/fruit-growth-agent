# 果序 Agent 中文完整演示指南

演示租户为“果序生鲜（华东）”。数据都是虚构样例，可安全用于产品展示。

## 演示数据

- 4 个角色：管理员、运营人员、审核人员、客服人员。
- 6 个商品：冰糖心苹果、云南昭通丑苹果、蓝莓、贵妃芒、玉露香梨、阳光玫瑰葡萄。
- 8 条知识：包含已通过、草稿、已拒绝、过期与冲突事实。
- 4 个审批：覆盖待处理、已批准和已拒绝状态。
- 5 个 Copilot 案例：包含售前咨询、售后问题、风险升级、引用快照与结果事件。

## 六步演示路线

1. 首页选择“运营人员”，点击“进入完整演示”，确认右上角显示租户与身份。
2. 打开“成员权限”，展示四类角色和租户内成员状态。
3. 打开“商品导入”，下载演示 CSV 后上传；指出一行合法、一行库存为负，系统逐行返回结果。
4. 打开“知识库”，展示不同审核状态、有效期和精确事实保护；可新建草稿并提交审核。
5. 打开“人工审批”，演示高风险动作只记录批准或拒绝，不连接真实退款、库存或发布执行器。
6. 打开“运营 Copilot”，输入“客户问冰糖心苹果现在多少钱，适合送礼吗？”，填写商品编码 `DEMO-APPLE-001`，展示分类、三条以内建议、引用依据、风险提示和结果记录。

## 推荐角色切换

- 运营人员：导入商品、维护知识、创建 Copilot 案例。
- 审核人员：审核知识和审批高风险建议。
- 客服人员：查看案例、编辑候选回复并记录结果。
- 管理员：查看成员与整体配置。

角色切换会签发新的短期本地会话。演示结束后关闭前后端进程即可；重新运行种子命令可恢复稳定的基准数据。
